### **Macro-Módulo 1: Investigador y Mapeador de Proyectos**

Este módulo se encarga de la introspección, tanto de la estructura del código como del contenido de los datos.

#### **1.1. Extractor de Código Fuente (Auditoría)**
[cite_start]Actualmente implementado en `extractor.py`[cite: 120], este sub-módulo realiza las siguientes tareas:
* [cite_start]**Generación del Árbol de Directorios:** Crea una representación visual de la estructura del proyecto (ej: `mapa_proyecto.txt`)[cite: 138, 140, 205].
* [cite_start]**Consolidación de Código:** Escanea recursivamente archivos con extensiones permitidas (`.py`, `.js`, `.java`, etc.) [cite: 122, 134] [cite_start]y genera un documento consolidado (PDF o TXT) que incluye el nombre del archivo y su código fuente íntegro[cite: 135, 136, 141].
* [cite_start]**Filtrado Inteligente:** Ignora automáticamente carpetas de entorno virtual (`.venv`, `node_modules`) y archivos binarios para evitar errores de codificación[cite: 121, 126, 158].

#### **1.2. Mapeador Inteligente de Datos (Data Mapping)**
[cite_start]Utiliza la lógica de `analizador_datos.py` [cite: 1] [cite_start]para procesar formatos estructurados (XLSX, XLS, XLSM, Parquet, CSV)[cite: 37]:
* [cite_start]**Detección de Esquema:** Identifica nombres de columnas (names) y tipos de datos (str/dtypes) mediante detección inteligente de encabezados[cite: 6, 11, 19, 28].
* [cite_start]**Estadísticas de Contenido:** Actualmente el sistema realiza un muestreo de valores únicos[cite: 2, 18, 23]. Para cumplir con tu requerimiento, se debe integrar:
    * **Head y Tail:** Lectura de las primeras y últimas 5 filas de cada hoja o archivo para el informe final.
* [cite_start]**Reportes Multiformato:** Genera un mapa detallado del archivo en formato TXT (por defecto) con opción de exportar a un reporte visual en PDF[cite: 42, 43, 45].

## 2. Macro-Módulo 1: Investigador y Mapeador de Proyectos
Este módulo se enfocará en la introspección técnica de directorios y el análisis profundo de archivos de datos estructurados.

### A. Extractor de Código Fuente (Auditoría)
* [cite_start]**Mapa de Directorios:** Debe generar una estructura visual del árbol de carpetas y archivos[cite: 127, 138, 187].
* [cite_start]**Consolidación de Código:** Escaneo recursivo para extraer el contenido de archivos de texto[cite: 127, 135].
    * [cite_start]**Formatos:** Generación obligatoria en TXT (ideal para análisis de IA) y opcional en PDF[cite: 128, 129, 136, 141].
    * [cite_start]**Contenido:** Cada sección debe iniciar con el nombre del archivo, seguido de su código fuente íntegro[cite: 136, 137].
    * [cite_start]**Filtros:** Se deben mantener las listas de exclusión para carpetas como `.git`, `node_modules` y `venv`[cite: 121, 150].

### B. Mapeador de Archivos de Datos (Data Mapping)
[cite_start]Se requiere una evolución del actual `analizador_datos.py` [cite: 1] para incluir:
* [cite_start]**Formatos Soportados:** XLSX, XLS, XLSM, Parquet y CSV[cite: 1, 20, 26, 37].
* **Atributos de Análisis:**
    * [cite_start]**Names:** Identificación de encabezados mediante puntuación inteligente[cite: 6, 11, 12, 23].
    * [cite_start]**Str/Dtypes:** Detección de tipos de datos (entero, decimal, fecha, texto)[cite: 33, 34, 35, 36].
    * [cite_start]**Head & Tail:** Incorporar la extracción de las primeras y últimas 5 filas de cada conjunto de datos (funcionalidad a desarrollar sobre la base de `_procesar_fila_datos`)[cite: 18].
* [cite_start]**Salida:** Informe técnico detallado guardado en TXT por defecto, con opción de exportación a PDF profesional[cite: 42, 43, 44, 45].
